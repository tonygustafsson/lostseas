# Character image generator prompts

Prompts for the 48 townsfolk portraits: a tavern character, a market character and the governor in each of the 16 towns. Each prompt is self-contained, so you can paste it straight into an image tool.

## How to use them

- Match the existing player portraits in `public/img/characters/`: detailed pixel art, warm light and a square 1254 × 1254 head and shoulders close-up with a period setting behind.
- The talk dialog crops the image to a circle and the card crops it to a wide strip, so keep the face near the centre with room around it.
- Save each image to the file path given. The game loads the portrait by the character's id.
- The description is the source of truth, because the dialogue refers to its details. If the tool drifts (wrong hair, missing scar), regenerate instead of changing the text.
- The game is set in 1640, so avoid tricorn hats, powdered wigs and other later fashions.

## Shared style

Detailed pixel art portrait in the style of a 1990s point-and-click adventure game, rich warm colours, soft lantern or sunlight glow, square 1:1 image, head and shoulders close-up, face near the centre, looking towards the viewer, background in softer detail.

Avoid: No text, letters, logos or watermarks. No modern objects. No tricorn hats, powdered wigs or other fashions later than 1640. No other people in focus.
